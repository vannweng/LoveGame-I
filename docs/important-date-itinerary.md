# 專屬約會行程：台北捷運示範版

## 已核准範圍

重要日當日在首頁顯示每一份行程；篇章中可提前查看、編輯。購買、訂票、訂位均在外部平台完成，LoveGame 不代訂、不收款，也不讀取外部預訂紀錄。

第一版不啟用付費 API、API 金鑰、計費帳戶、定位權限、AI 服務或即時交通查詢。地點與捷運路線來自本機靜態資料；按「開啟路線確認」才以現有外部瀏覽器服務開啟 Google Maps 一般路線頁。URL 的 `api=1` 為地圖連結格式，並非 Maps 計費 API 呼叫。

## 使用流程

1. 系統先提供免費景點示範行程。尚未回報的電影與餐廳不會顯示成已確認預訂。
2. 使用者到店家／平台自行訂好，再選擇分店或輸入名稱、完整地址、鄰近捷運站與步行時間。
3. 電影回報開演時間及片長／佔用時間，可選填片名；餐廳回報訂位時間及用餐長度。日期固定為本篇章的重要日。
4. 回報與對應任務結算一同透過 Journey repository 更新保存。已完成任務再次修改不重複給獎勵；到最終期限後仍可保存預訂，但不自動補算完成獎勵。
5. 系統保留固定預訂及使用者手動修改，重新安排其他空檔、交通與免費景點。

## 排程規則

- 本機捷運圖目前僅涵蓋紅線象山—士林、藍線西門—後山埤、綠線中正紀念堂—松山、文湖線大安—南京復興。
- 相鄰站暫以 3 分鐘、轉乘 8 分鐘、首次候車 8 分鐘估算，另加兩端步行；不是北捷正式時刻表。已知近距離信義區地點可直接步行轉場。
- 電影另預留開演前 20 分鐘、餐廳到店前 10 分鐘。交通段顯示路線與估算時間；緩衝保留在交通抵達後、固定活動開始前。
- 每段空檔至多加入一個 45 分鐘免費景點，單程估算不超過 35 分鐘，兩端合計不超過 60 分鐘。優先順路、再參考偏好與已知雷點。
- 免費項目限公共區域，不包含付費展覽、演出、官邸正館或店家消費。09:00–22:00 是保守排程窗口，部分景點限制到 18:00；實際開放以官方資訊為準。
- 預訂衝突或轉場不足時保留原時間並警告，不偷偷修改預訂、不硬插活動。更換景點若無可行替代會提示手動調整。
- 支援電影跨午夜結束，標示次日；早晚場提示確認捷運首末班車。尚未規劃住家出發／返家交通，亦無天氣、停駛、現場擁擠或票券自動驗證。
- 未知／舊地點先保留訂位，提示補齊地址與車站，不虛構零分鐘轉場。

## 架構與資料維護

- 地點、平台連結、參訪窗口：`src/content/taipeiPlanPlaces.ts`，各項帶官方／場館來源頁。
- 本機捷運圖：`src/content/taipeiMetro.ts`。
- 純排程與時間估算：`src/features/journey/domain/itinerary*.ts`、`metroEstimate.ts`、`planTime.ts`。
- 回報、編輯、更換景點由 application actions 經既有 repository 保存；UI 不直接呼叫資料庫或交通 API。
- 舊存檔保持 schemaVersion 1；沒有 plannerVersion 2 的行程依原訂位重建，保留手動活動，日期型別在反序列化時還原。
- 擴充地點或交通模式須另外確認產品範圍；現階段未加入爬蟲後台、商家合作或即時路線服務。

## 驗證

執行 `npm run lint`、`npm run typecheck`、`npm test`。行程測試涵蓋訂位順序、固定活動、衝突、跨午夜、景點限制、更換與手動編輯、舊資料、原子保存與不重複獎勵、外部路線 URL。

手動驗收：重要日篇章 → 修改預訂／行程 → 回報影城與餐廳 → 檢查固定時間、交通及免費景點 → 修改已完成預訂 → 重新整理確認保存 → 將 DEV 日期設為重要日當天確認首頁顯示。
